# 💼 Job & Resume Tracker

A console-based Python application designed to help users manage and track their job applications in one place.

The **Job & Resume Tracker** allows users to add job applications, view and search companies, update application status, delete applications, and filter jobs based on their current application stage.

---

## 📌 Project Overview

Keeping track of multiple job applications can become difficult when applications are submitted to different companies and for different roles.

This project provides a simple command-line solution for organizing job application information such as:

* Company name
* Job role
* Application status
* Interview date

The project was developed using **Python fundamentals**, including functions, lists, dictionaries, loops, conditional statements, and user input.

---

## ✨ Features

### 1. ➕ Add Job

Add a new job application by entering:

* Company name
* Job role
* Application status
* Interview date

### 2. 📋 View Jobs

Display all saved job applications and their details.

### 3. 🔍 Search Company

Search for a specific company and view its application details.

### 4. 🔄 Update Application

Update the application status and interview date of an existing job application.

### 5. 🗑️ Delete Application

Remove a job application using its Job ID.

### 6. 📩 Show Applied Jobs

Display applications currently marked as **Applied**.

### 7. 🎤 Show Interview Jobs

Display applications currently marked as **Interview**.

### 8. 🚪 Exit

Exit the Job & Resume Tracker application.

## ▶️ How to Run

### 1. Clone the repository

Open your terminal and run:

```bash
git clone https://github.com/codewithme-sania/job-resume-tracker-python.git
```

### 2. Open the project folder

```bash
cd job-resume-tracker-python
```

### 3. Run the Python program

```bash
python job_tracker.py
```

If `python` does not work on Windows, try:

```bash
py job_tracker.py
```
